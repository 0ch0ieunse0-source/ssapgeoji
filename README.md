# 거지노트

**내 생활비, 하루 단위로 지키기.**

주소: https://0ch0ieunse0-source.github.io/ssapgeoji/

한 달 생활비를 넣으면 하루 한도를 자동으로 나눠 주는 개인 가계부 웹앱이에요.
폰에서 열어 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

- **홈**: 남은 생활비, 오늘·이번 주 남은 돈, 무지출 챌린지, 예비비, 분류별 소비 리포트, 신용카드 결제 예정액, 친구한테 받을 돈
- **가계부**: 달력(한도 초과·무지출·약속 표시), 주간 한도, 날짜별 내역
- **아끼기**: 아낀 돈을 저축통장으로 옮긴 기록, 사고 싶은 것 대기 목록(하루/3일)
- **돈 일정**: 월급·고정지출·카드값 일정과 날짜별 통장 예상 잔액, 잔액 부족 경고
- **목표**: 저축 목표 진행률과 목표 경로 그래프, 자산 기록
- **처음 사용법**: 처음 열 때 주요 기능과 Safari·홈 화면 추가 방법을 안내해요. 카카오톡 같은 앱 안에서 열면 Safari로 열라고 알려줘요. (설정 → 사용법 다시 보기)
- **설정**: 매달 시작하는 날, 생활비, 한도, 통장·월급, 신용카드, 저축 목표, 백업

## 내 기록은 내 브라우저에만 저장돼요

- 서버, 데이터베이스, 로그인이 없어요. 적은 기록은 **지금 쓰는 기기의 브라우저(localStorage)에만** 저장돼요.
- 같은 주소를 다른 사람이 열어도 그 사람 브라우저에는 그 사람 기록만 있어요. 서로의 기록은 볼 수 없어요.
- 앱 이름은 아낌노트에서 거지노트로 바뀌었지만, 저장 이름(`aggim-v1`)은 그대로라 예전 기록도 그대로 보여요.
- 광고, 분석 도구, 추적 코드가 없어요. 외부로 나가는 요청은 글꼴(Google Fonts)을 불러오는 것뿐이에요.
- 브라우저 기록(사이트 데이터)을 지우거나 기기를 바꾸면 기록이 사라질 수 있어요.
  **설정 → 기록 보관 → 백업 파일 저장**으로 가끔 백업해 두고, 새 기기에서 **백업 불러오기**로 옮기세요.
- 시크릿(사생활 보호) 창에서는 창을 닫으면 기록이 사라져요.

## 로컬에서 실행하기

[Node.js](https://nodejs.org) 22 이상이 필요해요.

```bash
npm install
```

```bash
npm run dev
```

터미널에 나오는 주소(보통 `http://localhost:5173/ssapgeoji/`)를 브라우저에서 열어요.

그 밖의 명령:

| 명령 | 하는 일 |
|---|---|
| `npm test` | 날짜·돈 계산 테스트 실행 |
| `npm run build` | 배포용 파일을 `dist/`에 만들기 |
| `npm run preview` | 만든 배포용 파일을 미리 보기 |

## 배포하기 (GitHub Pages, 무료)

`main` 브랜치에 push하면 GitHub Actions가 **테스트 → 빌드 → 배포**를 자동으로 해요
(`.github/workflows/deploy.yml`). 테스트가 하나라도 실패하면 배포하지 않아요.

처음 한 번만 설정하면 돼요.

1. GitHub에서 **공개(Public)** 저장소를 `ssapgeoji`라는 이름으로 만들어요.
2. 이 폴더를 그 저장소의 `main` 브랜치에 push해요.
3. 저장소 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 골라요.
4. **Actions** 탭에서 배포가 끝나면(초록색 체크) `https://<내 GitHub 아이디>.github.io/ssapgeoji/`에서 열려요.

> 저장소 이름을 `ssapgeoji`가 아닌 다른 이름으로 하면 `vite.config.ts`의 `base: "/ssapgeoji/"`도 같은 이름으로 바꿔야 해요.
> 바꾸지 않으면 화면이 하얗게 나와요.

## 폴더 구조

```
src/
  lib/          날짜·돈 계산 (화면과 분리한 순수 함수) + 테스트(*.test.ts)
    period.ts     한 달 기간(periodOf, shiftPeriod), 하루 한도 자동 배분(splitFor)
    card.ts       카드 결제 주기(cardCycle)
    flow.ts       돈 일정과 날짜별 예상 잔액
    savings.ts    아낀 돈, 옮긴 돈, 대기 목록 시간
    goal.ts       저축 목표 계산
    storage.ts    localStorage "aggim-v1" 읽기·쓰기
  state/app.tsx 앱 데이터와 화면 이동
  views/        탭 화면 (홈, 가계부, 아끼기, 돈 일정, 목표, 설정)
  sheets/       바텀시트 (쓴 돈 적기, 하루 상세)
  components/   여러 화면에서 같이 쓰는 조각
  styles/       tokens.css(색·글꼴 디자인 토큰, 라이트·다크) + app.css
public/         manifest.json, 앱 아이콘
```
